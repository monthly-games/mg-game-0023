# 슈퍼셀 게임 디자인 철학 가이드

**작성일:** 2026-05-23
**프로젝트:** MG-0023 Colony Frontier

---

## 서론

이 문서는 슈퍼셀(Supercell)의 게임 디자인 철학을 분석하고, MG-0023 프로젝트에 이를 적용하는 방법을 설명합니다. 슈퍼셀은 클래시 오브 클랜(Clash of Clans), 클래시 로얄(Clash Royale), 브롤스타즈(Brawl Stars) 등의 히트작을 만든 핀란드의 게임 개발사입니다.

---

## 1. 슈퍼셀의 핵심 철학 5가지

### 1.1 "Focused on the Game" (게임에 집중)

**원칙:** 한 번에 한 가지에 완벽하게 집중

**구현:**
- 단순하고 명확한 핵심 메커닉 (2-3개)
- 복잡한 시스템 지양
- 플레이어가 항상 "무엇을 해야 할지" 명확히 인지

**MG-0023 적용:**
```
핵심 루프: 1) 자원 수집 → 2) 건물 건설 → 3) 배틀/방어
복잡도 최소화: 모든 행동은 3가지 핵심 액션으로 요약
```

### 1.2 "Smart & Simple" (간단하지만 똑똑하게)

**원칙:** 누구나 30초 안에 배울 수 있지만, 완벽히 마스터하는 데는 평생이 걸림

**구현:**
- 30초 튜토리얼 (실제 플레이 = 튜토리얼)
- 첫 5초 안에 보상/피드백
- 깊이 있는 전략적 선택

**MG-0023 적용:**
```dart
// 즉시 플레이 시작 - 별도 튜토리얼 없음
void main() {
  runApp(MaterialApp(
    home: SessionBattleScreen(), // 첫 화면에서 즉시 배틀
  ));
}
```

### 1.3 "Social First" (소셜 우선)

**원칙:** 게임은 혼자 하는 것이 아니라 함께하는 것

**구현:**
- 클랜/길드 시스템
- 친구와의 배틀
- 리더보드 경쟁
- 협력 콘텐츠

**MG-0023 적용:**
```
소셜 기능:
1. 콜로니 클랜 (최대 50인)
2. 친구 배틀 (친근전)
3. 글로벌 리더보드
4. 클랜 전쟁 (주간 이벤트)
```

### 1.4 "Live the Game" (게임을 살다)

**원칙:** 개발자들이 자신의 게임을 즐기며, 커뮤니티와 소통

**구현:**
- 개발자 계정으로 플레이
- 커뮤니티 피드백 즉각 반영
- 주간 업데이트
- 투명한 밸런싱

**MG-0023 적용:**
```
개발 문화:
- 모든 개발자는 매일 1시간 이상 게임 플레이
- Discord/커뮤니티에 직접 참여
- 긴급 이슈는 24시간 내 수정
```

### 1.5 "Forever Beta" (영원한 베타)

**원칥:** 게임은 완성되는 것이 아니라 계속 진화

**구현:**
- 지속적인 업데이트
- A/B 테스트
- 메타 게임 변화
- 시즌 이벤트

**MG-0023 적용:**
```
업데이트 주기:
- 주간 밸런스 패치
- 월간 신규 유닛/카드
- 분기별 대규모 업데이트
```

## 2. 슈퍼셀 스타일 게임 루프

### 2.1 세션 기반 플레이 (Session-Based)

**특징:**
- 한 세션: 3-5분
- 즉시 시작 가능
- 명확한 승/패 조건
- "한 번 더"의 중독성

**다이어그램:**
```
시작 → 매칭(초) → 배틀(3분) → 결과/보상 → "한 번 더?" → 반복
          ↑______________________________|
```

### 2.2 보상 시스템 (Chest System)

**특징:**
- 상자 오픈의 기대감
- 시간 기반 오픈 (2시간, 8시간, 24시간)
- 랜덤성 + 확정 보상
- 상자 슬롯 관리

**보상 종류:**
```
1. 실버 상자 (2시간) - 흔한 카드
2. 골드 상자 (8시간) - 희귀 카드
3. 마법 상자 (즉시) - 랜덤 카드
4. 전설 상자 (24시간) - 전설 카드 확정
5. 클랜 상자 (기증) - 클랜원이 보내는 상자
```

### 2.3 진화 시스템 (Progression)

**특징:**
- 레벨 기반 해금
- 카드 업그레이드
- 경기장(Arena) 진급
- 트로피 시스템

## 3. 슈퍼셀 UI/UX 원칙

### 3.1 즉시 피드백 (Instant Feedback)

- 모든 액션에 0.1초 내 시각/청각 피드백
- 탭 시 즉시 응답
- 애니메이션은 빠르고 명확하게 (0.2-0.3초)

### 3.2 명확한 정보 계층 (Clear Information Hierarchy)

```
1차: HP, 시간, 엘릭서 (항상 표시)
2차: 현재 카드/유닛 상태
3차: 배틀 통계
4차: 설정/옵션
```

### 3.3 감정적 연결 (Emotional Connection)

- 승리 시 화려한 이펙트
- 패배 시 "아쉬움"을 남기는 디자인
- 친구와 함께할 때 특별 보상
- 리더보드 상승 시 알림

## 4. MG-0023에 적용된 슈퍼셀 요소

### 4.1 세션 배틀 시스템

**파일:** `lib/supercell_style/session_battle.dart`

**구현 요소:**
- 3분 타임 세션
- 엘릭서 기반 카드 플레이
- 즉시 매칭 (AI 전)
- "한 번 더" 버튼
- 실시간 배틀 통계

### 4.2 카드/유닛 시스템

**카드 종류:**
```dart
BattleCard(
  elixir: 3,        // 비용 (1-10)
  damage: 15,        // 위력
  type: TROOP,       // 유닛/주문/건물
  rarity: COMMON,    // 등급
)
```

### 4.3 소셜 기능 구현 계획

| 기능 | 상태 | 구현 파일 |
|------|------|----------|
| 세션 배틀 | ✅ 완료 | session_battle.dart |
| 리더보드 | 🚧 진행중 | leaderboard_system.dart |
| 클랜 시스템 | 📋 계획 | clan_system.dart |
| 친구 배틀 | 📋 계획 | friendly_battle.dart |
| 상자 보상 | 📋 계획 | chest_system.dart |
